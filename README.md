## 📌 Project Overview
This repository contains the complete source code and assets for my personal portfolio website. The objective of this project is to provide recruiters, project managers, and prospective clients with an intuitive overview of my technical deliverables, workflow proficiencies, and contact pathways.

### Key Highlights
* **Responsive Layout:** Adaptive design tested across mobile, tablet, and desktop viewports.
* **Project Showcases:** Interactive cards detailing features, tech stacks, and direct links to live demos and GitHub repositories.
* **Performance Focused:** Minimalist asset bundling and fast page-load benchmarks.
* **Structured Information Architecture:** Clear separation between about sections, core competencies, featured works, and communication channels.

## 🚀 Getting Started

Follow these instructions to run a copy of the project locally for development or testing purposes.

### Prerequisites

* A modern web browser (Chrome, Edge, Firefox, Safari)
* [Node.js](https://nodejs.org/) installed (v18.x or later recommended, if using package managers)
* [Git](https://git-scm.com/) installed on your local machine

### Installation & Local Setup

1. **Clone the repository:**

git clone [https://github.com/danieldazong/Original-Daniel-Portfolio-website.git](https://github.com/danieldazong/Original-Daniel-Portfolio-website.git)
cd Original-Daniel-Portfolio-website




2. **Install dependencies** *(if using an npm-based project)*:

npm install


3. **Run the local development server:**

npm run dev



*If this is a static HTML/CSS/JS site, simply open `index.html` in your browser or run a local server (e.g., VS Code Live Server).*
4. **Build for production:**

npm run build
